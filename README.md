# Chemistry Quiz BD v3

- 100 original practice MCQs per chapter (1000 total), unique question IDs and text.
- Exam count follows selected marks/questions; if pool is large enough, 100 marks gives 100 questions.
- Immediate correct/wrong feedback plus answer review.
- Board Question Hub with board/year metadata and official portal link. Full copyrighted past-paper text is not bundled; add authorized content to `public/data/board_questions.json`.
- PWA, localStorage, no Supabase.

Run:
```bash
npm install
npm run dev
```
Build:
```bash
npm run build
```
